# Grace Temitayo Olorunfemi — Portfolio

A mobile-first portfolio built with plain HTML5 and CSS3.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `Grace_Temitayo_Olorunfemi_CV.pdf` — add your real CV here before using the Download CV button

## Customize first
1. Replace the email address in `index.html`.
2. Replace the `#` social links with your real profiles.
3. Put your real CV PDF beside `index.html` using the filename shown above.
4. Replace or expand project descriptions as needed.
5. Open `index.html` in a browser.

The navigation uses a CSS-only mobile menu, so no JavaScript is required.
